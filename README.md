# Mera Dost

Mera Dost is a personal productivity companion being built from scratch as a learning project.

## Goal

The objective of this project is to learn and apply:
- HTML
- CSS
- Python (Flask)
- C++
- Git & GitHub

while building a real-world web application.

## Status

🚧 Work in Progress

This project is being developed over a 15-day learning journey.

## Planned Features

- Task Management
- Goal Tracking
- Study Planner
- Progress Dashboard
- Notes
- Productivity Analytics
- AI-powered Suggestions
- Modern Responsive UI
